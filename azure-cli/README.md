# Azure CLI

`az` CLI examples wrapped as Bash scripts, by topic. Each script has its own README with
usage examples. Scripts use placeholders instead of hardcoded values and never assume a
default subscription — set one with `az account set --subscription <subscription-id>`.

- **vm**
  - [`vm/create-vm.sh`](vm/README.md)
- **jit**
  - [`jit/az-jit-request.sh`](jit/README.md)
- **pim**
  - [`pim/az-pim-activate.sh`](pim/README.md)
